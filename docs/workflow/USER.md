# Target User — Alex Rivera (Proxy)

**Role:** Account Executive / Client Delivery PM  
**Company:** Distributed B2B services firm (~150 people, 12 countries)  
**Tools today:** HubSpot (CRM), Gmail, Jira (delivery), Zoom  
**Call volume:** 8–12 client calls per week (discovery, sync, renewal)

---

## Job-to-be-done

> After every client call, turn what was said — plus what we already know about the account — into sent follow-up emails, updated CRM records, and team tasks, without spending 30+ minutes on admin.

---

## Current pain (observational / proxy assumptions)

| Pain | Evidence |
|------|----------|
| 25–40 min post-call admin per call | Timed baseline (Day 1) |
| CRM often stale until end of day | Deal stage lags reality |
| Out-of-scope asks missed until sprint planning | Scope creep on 2/10 recent projects (proxy) |
| Generic ChatGPT summaries ignore account history | Naive ChatGPT baseline misses context |
| Copy-paste between tools | HubSpot → Gmail → Jira manual |

**Frequency:** 8–12× per week = **4–8 hours/week** on post-call admin alone.

---

## What success looks like for Alex

1. Record or upload call → system pulls HubSpot context automatically
2. Scope Verifier flags anything outside SOW before team commits
3. Review proposed email + CRM + tasks in one screen
4. Click Execute → Gmail sends, HubSpot updates, Jira tickets created
5. Full audit trail if client disputes what was agreed

**Target:** <8 minutes per call (vs 30–40 manual).

---

## Assumptions (proxy user — state clearly in case study)

- Alex has HubSpot, Gmail, and Jira access
- SOW is available as PDF per client project
- Calls are in English (v1)
- Alex is comfortable approving AI drafts but never auto-sends without review
- Synthetic transcripts used for eval; real calls anonymized if available

---

## Non-developer interaction model

Alex never touches: terminal, JSON files, API keys (admin sets up once).  
Alex does: connect accounts (OAuth), select deal, record/upload, review inbox, click Execute.
